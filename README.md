## 🌟 Особенности проекта

- 🪶 **Аутентичный пиксель-арт:** нативное разрешение **48×48 px**, строгая 14-цветная палитра, 1-битная альфа-прозрачность и целочисленное масштабирование (*Nearest Neighbor* 4x) без замыливания.
- ⚡ **Легковесность и автономность:** написан на чистом **C# / WPF (.NET 4.8)**, не требует Electron, Node.js или тяжелых рантаймов. Готовый исполняемый файл весит всего **~19 КБ** и не нагружает систему.
- 🪟 **Нативная интеграция с Windows:** живёт прямо на панели задач, поддерживает многомониторные конфигурации, DPI-масштабирование (100%–200%) и всегда находится поверх окон.

## 🎭 Состояния питомца (FSM)

| Состояние | Описание | Анимация |
| :--- | :--- | :--- |
| **Покой (`IDLE`)** | Совёнок сидит на панели задач, дышит грудкой и моргает каждые 3.5–5.5 секунд. | 4 кадра дыхания + кадр моргания |
| **Ходьба (`WALK`)** | Разворачивается в профиль 90° и вышагивает вдоль панели задач. Шаги строго синхронизированы с перемещением (*Step-Locked*). При касании края экрана разворачивается. | 4 кадра шага (подъём лапок, балансир хвостом) |
| **Сон (`SLEEP`)** | Если не трогать совёнка в течение **10 секунд**, он сладко засыпает: закрывает глазки, дышит и пускает пиксельные частицы `Zzz`. Мгновенно просыпается от клика. | 4 кадра глубокого дыхания + подъём `Zzz` |
| **Полёт (`FLY`)** | При активном перетаскивании курсором мыши расправляет крылья и переходит в полёт. Поворачивается в сторону движения курсора. При отпускании в воздухе плавно планирует вниз на пол. | 6-тактный ping-pong цикл (85 мс на такт) |

## 🖱️ Управление и интерактивность

- **ЛКМ (одиночный клик):**
  - Будит спящего совёнка.
  - В бодрствующем состоянии переключает режим между **Покоем** и **Прогулкой**.
- **ЛКМ (зажатие и перетаскивание):**
  - Поднимает совёнка в воздух и активирует **Полёт**.
  - Курсор намертво зафиксирован на питомце без проскальзывания и джиттера.
  - Если отпустить в воздухе — включается **мягкое планирующее приземление** обратно на панель задач.
- **ПКМ (клик по питомцу):**
  - Контекстное меню быстрого управления:
    - *Сменить состояние (Покой / Ходьба)*
    - *Уложить спать / Разбудить*
    - *Полёт / Приземлиться*
    - *Выход*
- **Иконка в системном трее:**
  - Позволяет управлять питомцем из области уведомлений Windows рядом с часами.

## 🚀 Быстрый старт

### 1. Запуск
Просто дважды кликните по [**`DesktopPet.exe`**](DesktopPet.exe) или запустите скрипт [**`start.bat`**](start.bat). Никаких сторонних программ устанавливать не нужно!

### 2. Сборка из исходников
Если вы хотите изменить код в [`Program.cs`](Program.cs), пересобрать проект можно за 1 секунду стандартным компилятором Windows:
```cmd
build.bat
```
*(Скрипт использует встроенный в Windows `csc.exe` из папки .NET Framework — Visual Studio не требуется).*

### 3. Инспектор анимаций в браузере
В проект встроен удобный HTML5-инспектор [`test_viewer.html`](test_viewer.html). Откройте его в любом браузере, чтобы:
- Переключать анимации (Покой, Моргание, Походка, Сон, Полёт).
- Менять зум (1x–8x) и включать пиксельную сетку.
- Управлять скоростью (FPS) и по кадрам изучать анатомические координаты.
- Смотреть 14-цветную палитру проекта.

### 4. Автоматические тесты (CI)
Для проверки целостности всех спрайтов и логики переходов FSM запустите:
```cmd
scripts\run_all_tests.bat
```
*Набор включает 40 тестов валидации ассетов (разрешение 48x48, 1-бит альфа, отсутствие мусора) и 17 тестов физики перемещения.*
